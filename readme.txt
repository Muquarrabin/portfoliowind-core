Companion core plugin for the PortfolioWind theme providing Portfolio Projects CPT, taxonomies, and Elementor section shortcodes.

== Description ==

PortfolioWind Core is the official companion plugin for the PortfolioWind WordPress theme. It provides:

* **Portfolio Projects Custom Post Type (`portfoliowind_proj`)**: Create rich case studies with project client details, project timeline, role, live demo URL, and GitHub repository links.
* **Project Categories Taxonomy (`portfoliowind_project_category`)**: Organize your case studies into distinct filterable categories.
* **Case Study Meta Boxes**: Dedicated outcome metrics (KPI 1, KPI 2, KPI 3) and external mockup fallbacks.
* **Elementor Section Shortcodes**: Embed any portfolio section directly via shortcode `[portfoliowind_hero]`, `[portfoliowind_about]`, `[portfoliowind_services]`, `[portfoliowind_projects]`, `[portfoliowind_resume]`, `[portfoliowind_blog]`, `[portfoliowind_contact]`, or `[portfoliowind_all]`.

== Installation ==

1. Upload the entire `portfoliowind-core` folder to the `/wp-content/plugins/` directory, or install `portfoliowind-core.zip` via **Plugins > Add New > Upload Plugin**.
2. Activate the plugin through the **Plugins** menu in WordPress.
3. You will now see the **Projects** menu in your WordPress admin sidebar.

== Frequently Asked Questions ==

= Do I need the PortfolioWind theme to use this plugin? =
While this plugin was engineered as the official companion for PortfolioWind, the Portfolio Projects custom post type, taxonomies, and meta boxes work smoothly on any WordPress theme.

= Where do I manage my portfolio case studies? =
Once activated, navigate to **wp-admin > Projects** to add, edit, or categorize your case studies.

= How do I embed a portfolio section into Elementor? =
You can use the built-in shortcodes, such as `[portfoliowind_hero]`, `[portfoliowind_about]`, `[portfoliowind_projects]`, or `[portfoliowind_all]`.
