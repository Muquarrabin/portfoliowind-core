# PortfolioWind Core — Companion Plugin

Official core companion functionality for the **[PortfolioWind Theme](https://github.com/Muquarrabin/portfoliowind-theme)**, providing custom case studies, taxonomies, measurable outcome KPIs, and Elementor section shortcodes.

## Features

- **Projects Custom Post Type (`portfoliowind_proj`)**: Publish in-depth case studies with client details, timeline, role, live preview URL, GitHub repository links, and tech stack tags.
- **Project Categories Taxonomy (`portfoliowind_project_category`)**: Organize your case studies into distinct filterable categories.
- **Outcome Metrics & KPIs**: Dedicated meta boxes for measurable deliverables (e.g., *99.99% Uptime*, *< 200ms Latency*, *4.2x Query Speed*).
- **Elementor Section Shortcodes**: Embed any portfolio section anywhere via shortcodes:
  - `[portfoliowind_hero]`
  - `[portfoliowind_about]`
  - `[portfoliowind_services]`
  - `[portfoliowind_projects]`
  - `[portfoliowind_resume]`
  - `[portfoliowind_blog]`
  - `[portfoliowind_contact]`
  - `[portfoliowind_all]`

## Installation

1. Download or clone this repository into `/wp-content/plugins/portfoliowind-core`:
   ```bash
   cd wp-content/plugins/
   git clone https://github.com/Muquarrabin/portfoliowind-core.git portfoliowind-core
   ```
2. Navigate to **Plugins > Installed Plugins** in your WordPress admin.
3. Locate **PortfolioWind Core** and click **Activate**.
4. The **Projects** menu will now appear in your WordPress sidebar.

## Requirements

- WordPress 5.8 or higher
- PHP 7.4 or higher
- PortfolioWind WordPress theme (recommended) or any modern WordPress theme
